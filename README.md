Stock Prediction with Hybrid BPNN-LightGBM-Diffusion Framework
Repository Overview
This repository hosts the source code for a hybrid time-series prediction framework designed to forecast stock price movements (up/down) and returns. The framework addresses non-Gaussian data characteristics and time-varying volatility using diffusion models, ensuring robust performance across market conditions.

2. Data Description
Data Source
The project uses futures market data supplemented with technical indicators. The raw data (df_futures.csv) and feature-engineered data (df_futures_with_features.csv) are included in the factor_pac directory.
Data Format
Raw data (df_futures.csv): Contains basic market data (open, high, low, close, volume, etc.).
Feature-engineered data (df_futures_with_features.csv): Includes 25+ technical indicators (e.g., MFI, RSI, MACD) calculated via factors.py.
Data Usage
Technical indicators are generated by running factors.py on raw data.
The processed data is used for training 8 hybrid models (2 validation modes × 4 architectures).

4. Model Architectures (8 Total)
The framework trains 4 model types across 2 validation modes:
Model Type	Validation Modes	Task
Linear Regression	val_at_end, val_in_middle	Return prediction (regression)
Single BPNN	val_at_end, val_in_middle	Up/down probability (classification)
LightGBM-BPNN Fusion	val_at_end, val_in_middle	Weighted hybrid prediction
LightGBM-BPNN-Diffusion Fusion	val_at_end, val_in_middle	Noise-corrected hybrid prediction

5. Reproducibility Notes
Random Seeds: All random processes (PyTorch, NumPy) are seeded with 42 to ensure consistent results.
Weight Optimization: LightGBM-BPNN fusion weights are dynamically optimized via SLSQP (constraints: w1 + w2 = 1, w2 ≥ 0.2).
Diffusion Noise: The diffusion model uses a cosine beta schedule (T=300) to handle time-varying volatility.
